## 1. Module Summary

Students learn to make a clear, good-looking slide presentation in Microsoft PowerPoint: adding
slides, typing and formatting text, using a design theme, adding pictures, a table and a chart,
moving between slides with transitions and simple animations, and showing the slides full
screen. The module ends with a project: a short presentation for a real purpose.

**Why it matters**: shops, schools, offices and NGOs in Pakistan use slides to explain an idea,
a product or a result. A student who can make a neat 6-slide presentation can help at work, in
college, and in freelancing jobs.

**Prerequisites**: Module 1, Module 2 (typing), and Module 4 (Word). PowerPoint uses the same
ribbon, the same text formatting and the same saving as Word, so lessons link back to Word
instead of re-teaching it.

**What is NOT here**: how to speak in front of people. That is Module 6 (Presentation Skills).

**Target software**: **PowerPoint 2021** on Windows (lab computers; owner confirmed 2026-10-14).
- Every step comes from a Microsoft page whose "Applies to" list includes PowerPoint 2021
  (Microsoft's "PowerPoint for Windows training" pages list PowerPoint 2021).
- A step that cannot be confirmed goes in an "If your screen looks different" box with a
  confirmed backup way, and in the owner's private test list.
- Features that need a Microsoft 365 subscription (for example Designer suggestions or Copilot)
  are not taught.

**Keyboard shortcuts**: only when a Microsoft page lists them for PowerPoint.

**Pictures**: no copied images. Main-window screenshots follow Microsoft's screenshot rules
(book-spec v1.4) and are added only from the owner's own lab screenshots.

## 2. Learning Outcomes

By the end of Module 5, the student can:

- **LO-1**: Open PowerPoint, start a blank presentation and name the main parts of the window.
- **LO-2**: Add new slides, choose a slide layout, and type a title and points.
- **LO-3**: Save a presentation, open it again, and show it full screen as a slide show.
- **LO-4**: Format text on slides (font, size, colour, bullets).
- **LO-5**: Give the whole presentation a matching look with a design theme.
- **LO-6**: Add a picture and a shape to a slide.
- **LO-7**: Add a table and a simple chart to a slide.
- **LO-8**: Put slides in order: move, copy and delete slides.
- **LO-9**: Add a transition between slides.
- **LO-10**: Add a simple animation to text or a picture.
- **LO-11**: Write speaker notes and print handouts or notes pages (preview if no printer).
- **LO-12**: Plan and make a 6-slide presentation for a real purpose.

The common lesson criteria (Module 1 spec §4, AC-C1 to AC-C11, with book-spec v1.4), plus:
- **AC-P1**: Every PowerPoint step cites a Microsoft page whose "Applies to" list includes
  PowerPoint 2021, or sits in an "If your screen looks different" box with a confirmed backup.
- **AC-P2**: Every example presentation has a real purpose in Pakistan (a shop's new products,

## 5. Lessons in Detail (topics; facts verified when each lesson is written)

### 5.1 Starting PowerPoint and the PowerPoint Window
- **In scope**: opening PowerPoint (Start menu; Windows 10/11 tabs if different), Blank
  Presentation, the slide pane, the slide thumbnails, the ribbon, placeholders, Normal view.
- **Builds on**: Word Lesson 4.1 (ribbon, tabs).

### 5.2 Adding Slides and Typing Text
- **In scope**: New Slide, slide layouts (Title Slide, Title and Content), typing in
  placeholders, adding bullet points.

### 5.3 Saving, Opening and Showing a Slide Show
- **In scope**: Save As, file name, folder (links to Word Lesson 4.3); opening; starting the
  slide show from the beginning and from the current slide; moving to the next slide; ending
  the show.

### 5.4 Formatting Text on Slides
- **In scope**: font, size, colour, bold; bullet and numbered lists; alignment (links to Word
  Lessons 4.5–4.7).

### 5.5 Design Themes
- **In scope**: the Design tab, choosing a theme, theme variants (if confirmed for 2021).
- **Out of scope**: slide masters; Designer (Microsoft 365 only).

### 5.6 Pictures and Shapes on Slides
- **In scope**: inserting a picture from the computer, resizing and moving it, inserting a
  shape (links to Word Lesson 4.10).

### 5.7 Tables and Charts on Slides
- **In scope**: inserting a table on a slide; inserting a simple column chart and typing its
  data (links to Excel Lesson 7.11).

### 5.8 Organizing Slides
- **In scope**: moving slides in the thumbnail pane, Slide Sorter view, duplicating and
  deleting a slide.

### 5.9 Slide Transitions
- **In scope**: the Transitions tab, choosing a transition, applying it to all slides,
  previewing it.

### 5.10 Simple Animations
- **In scope**: the Animations tab, one entrance animation on text or a picture, previewing.
- **Out of scope**: animation pane in depth, motion paths.

### 5.11 Speaker Notes and Printing
- **In scope**: the Notes pane, printing handouts or notes pages, print preview (no printer
  needed).

### 5.12 Project: A Presentation for a Real Purpose
- **In scope**: planning 6 slides on paper first, then making them with a theme, pictures, a
  table or chart, transitions; showing the slide show.
