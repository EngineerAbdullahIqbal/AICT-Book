## 1. Module Summary

Students learn to make, change, save and print real documents in Microsoft Word. The module
ends with two documents students will use in real life: a job application letter and a CV.

**Prerequisites**: Module 1 (mouse, keyboard, desktop, files and saving). Module 2 typing
practice helps but is not required.

**Target software**: **Microsoft Word 2016 / Word 2019** on Windows (the lab computers).
- Every step comes from a Microsoft Support page that applies to Word 2016 or Word 2019.
  The page's "Applies to" list must include one of them.
- A step that can't be confirmed for these versions goes in an UNVERIFIED box
  (constitution §4). The owner tests it on a lab computer.
- Windows 10/11 tabs are needed only where a step happens outside Word (for example opening
  Word from the Start menu).

**Keyboard shortcuts**: allowed only when a Microsoft Support page lists them for Word.
Never invented.

**Pictures**: no screenshots tonight. Each lesson may have `:::info[Screenshot to add]` boxes
(book-spec §4).

**Practice data**: students type short texts and tables shown on the page. No files to
download.

## 2. Learning Outcomes

By the end of Module 4, the student can:

- **LO-1**: Open Word, start a blank document and name the main parts of the Word window.
- **LO-2**: Type text, correct mistakes and undo a change.
- **LO-3**: Save a document with a name in a chosen folder, close it, and open it again.
- **LO-4**: Select text, and copy, cut and paste it.
- **LO-5**: Change the font, size, colour and style (bold, italic, underline) of text.
- **LO-6**: Change paragraph alignment and line spacing.
- **LO-7**: Make bulleted and numbered lists.
- **LO-8**: Find and fix spelling and grammar mistakes.
- **LO-9**: Insert a table and type data into it.
- **LO-10**: Insert a picture and a shape.
- **LO-11**: Set margins and page orientation, preview a document, and print it.
- **LO-12**: Write and format a job application letter.
- **LO-13**: Make a simple one-page CV.

## 5. Lessons in Detail

All items are *topics*. The facts and steps are verified when each lesson is written.

### 4.1 Starting Word and the Word Window
- **Goal (draft)**: open Word, start a blank document and point to the main parts of the window.
- **In scope**: opening Word from the Start menu (Windows 10/11 tabs if different), blank
  document, ribbon, tabs, groups, the typing area, the cursor (insertion point), the status
  bar, closing Word.
- **Out of scope**: templates, Word settings, Microsoft account sign-in.
- **Diagram idea**: Word window parts, top to bottom.

### 4.2 Typing and Correcting Text
- **In scope**: typing a sentence, Enter for a new paragraph, Backspace and Delete, moving the
  cursor with the arrow keys and the mouse, Undo and Redo.
- **Out of scope**: selecting text (4.4), formatting.

### 4.3 Saving, Closing and Opening a Document
- **In scope**: Save As the first time, choosing a folder, giving a file name, Save again
  after changes, closing a document, opening it again.
- **Out of scope**: OneDrive, file formats other than the normal Word document.
- **Common mistake to include**: saving without choosing a folder.

### 4.4 Selecting Text: Copy, Cut and Paste
- **In scope**: selecting a word, a line and a paragraph with the mouse; copy, cut, paste.
- **Out of scope**: paste options in depth, the clipboard pane.

### 4.5 Formatting Text: Font, Size and Style
- **In scope**: font, font size, bold, italic, underline, font colour.
- **Out of scope**: styles, text effects.

### 4.6 Formatting Paragraphs: Alignment and Line Spacing
- **In scope**: left, centre, right and justify alignment; line spacing.
- **Out of scope**: indents in depth, tab stops.

### 4.7 Bulleted and Numbered Lists
- **In scope**: making a bulleted list, a numbered list, ending a list.
- **Out of scope**: multilevel lists, custom bullets.

### 4.8 Checking Spelling and Grammar
- **In scope**: the red and blue underline marks (verify exact colours for 2016/2019), fixing
  a word from the right-click menu, running the spelling and grammar check.
- **Out of scope**: custom dictionaries, language settings.

### 4.9 Tables
- **In scope**: inserting a table with a set number of rows and columns, typing in cells,
  moving between cells, adding a row.
- **Out of scope**: table styles in depth, merging cells, formulas in tables.
- **Practice**: a class timetable or a shop price list.

### 4.10 Pictures and Shapes
- **In scope**: inserting a picture from the computer, resizing it, inserting a shape.
- **Out of scope**: online pictures, text wrapping in depth, SmartArt.
- **Note**: the owner must make sure each lab computer has at least one picture file to use.

### 4.11 Page Setup and Printing
- **In scope**: margins, portrait and landscape, paper size, print preview, printing.
- **Out of scope**: sections, headers and footers, columns.
- **Note**: the task must still work if the lab has no printer (preview only).

### 4.12 Project: A Job Application Letter
- **In scope**: the parts of a formal letter; typing and formatting a letter using 4.2–4.8 and
  4.11.
- **Out of scope**: mail merge, templates.

### 4.13 Project: Your CV
- **In scope**: the parts of a simple one-page CV; using headings, lists and a table from
  4.5–4.9; saving and printing.
- **Out of scope**: CV templates, photos (optional, owner decides).
