# Steps to test on a lab computer (private list for the owner)

Updated 2026-10-13 after a second, deeper search of Microsoft's documentation. These steps could not
be confirmed for Office 2021 (or Windows 10/11 for Module 1). On the lesson pages they appear
as an "If your screen looks different" box that gives students a confirmed backup way.
Test each one; if it works, tell Claude and the box is removed. If not, tell Claude what you saw.

## Module 4: MS Word 2021 (6)

Re-checked for **Word 2021** on 2026-10-14. On a Word 2021 lab computer, check:

- [ ] **Lesson 4.2, step 14**: when you close Word without saving, which buttons does the message show: **Don't Save**, or **Yes / No / Cancel**?
- [ ] **Lesson 4.3, step 5**: after **File > Save As > Browse**, does **Documents** appear in the list on the left of the Save As box?
- [ ] **Lesson 4.4, step 12**: are **Cut** and **Copy** in the **Clipboard** group on the **Home** tab?
- [ ] **Lesson 4.9, step 15**: does pressing **Tab** in the bottom-right cell of a table add a new row?
- [ ] **Lesson 4.9, step 17**: is the table tab called **Layout** or **Table Layout**? Is **Insert Below** on it?
- [ ] **Lesson 4.11, step 6**: is there a **Size** button on the **Layout** tab, with **A4** in its list?
- [ ] *(No box, but worth a look)* **Lesson 4.8**: do **F7** and **Review > Editor** open the **Editor** pane with **Corrections > Spelling / Grammar**?

## Module 5: MS PowerPoint 2021 (8)

Written for **PowerPoint 2021** on 2026-10-14. On a PowerPoint 2021 lab computer, check:

- [ ] **Lesson 5.1, step 5**: is **Blank Presentation** on the start screen, or do you select **New** first?
- [ ] **Lesson 5.3, step 3**: after **File > Save as > Browse**, does **Documents** appear in the Save As box?
- [ ] **Lesson 5.3, step 10**: if the file is not in the recent list, does **File > Open > Browse > Documents > (file) > Open** work?
- [ ] **Lesson 5.4, step 8**: is there a **Center** button in the **Paragraph** group of the **Home** tab? (Backup: right-click > **Paragraph** > **Alignment** > **Center** > **OK**; check **OK** too.)
- [ ] **Lesson 5.5**: does choosing a theme change all slides at once? (Backup: right-click the theme > **Apply to All Slides**.)
- [ ] **Lesson 5.7, steps 3 and 11**: is the table grid easy to use (backup: **Insert Table**)? Does the chart's sample data have columns C and D, and does dragging the lower-right handle left remove Series 2 and 3? Does the chart worksheet have its own **X** button?
- [ ] **Lesson 5.9, step 3**: is **Gallery** visible in the transitions row without opening the full list?
- [ ] **Lesson 5.10, step 3**: is **Fly In** visible in the animations row? (Backup: the **More** arrow.)
- [ ] *(No box, worth a look)* **5.10**: a small animation marker appears next to the animated picture; **5.11**: the **3 Slides** handout preview shows lines for notes.

## Module 1: Computer Basics (4)

- [ ] **Lesson 1.8: Files, Folders, Saving and Deleting**: Microsoft's Paint pages for Windows 10 and Windows 11 do not give steps 7 to 10. Teacher: before class, test them on Windows 11 (laptop) and Windows 10 (lab computer). Check where the **Pencil** tool is, the names **File** and **Save as**, and how to choose the folder in the saving box. If **File** or **Save as** is different, press **F12** in Paint instead. Microsoft says F12 saves the picture as a new file, on both versions.
- [ ] **Lesson 1.8: Files, Folders, Saving and Deleting**: Microsoft does not say which app opens a picture when you double-click it. Teacher: before class, check which app opens **My House** on each version. Any app that shows the drawing is fine. To open it in Paint instead: open Paint and press **Ctrl+O** (open an existing picture).
- [ ] **Lesson 1.4: Starting Up and Shutting Down Safely**: The power button is in a different place on each computer model, so no guide can show it. Teacher: before class, find the power button on the lab computer case and on the monitor. Check that one press starts the computer.
- [ ] **Lesson 1.5: Using the Mouse**: To close the menu, click once on an empty part of the page. Teacher: check this in the lab computer's web browser before class. If the menu stays open, press the **Esc** key. Microsoft says Esc leaves the current task and closes a menu.

## Module 2: Typing Skills (TypingMaster 10/11)

These TypingMaster steps come from the official TypingMaster **11** manual. Check them in the lab's
TypingMaster 10/11. Each one already has an "If your screen looks different" box with Notepad as
the backup.

- [ ] **Lesson 2.1**: opening TypingMaster from the desktop icon; the New User screen ('User name' field, 'Enter'); the Course Selection screen; pressing 'Start Course' (twice); the 'Close' button at the top right.
- [ ] **Lesson 2.2**: 'Courses' in the right-hand menu opens the last lesson; the next exercise is highlighted; the key to press turns green after 2 seconds; two hands with a green dot show the finger.
- [ ] **Lesson 2.3**: the '>>' button moves to the next lesson.
- [ ] **Lessons 2.4 and 2.5**: going on to the next lesson of the Touch Typing Course (may be locked in a trial copy: only the first two lessons open).
- [ ] **Lesson 2.6**: 'Change course' at the top of the screen; the 'Numbers Course'; 'Start Course' / 'Continue Course' (advanced courses may be locked in a trial copy).
- [ ] **Lesson 2.7**: continuing the next lesson in the Touch Typing Course.
- [ ] **Lesson 2.8**: the menu on the right, 'Typing Test', test text (section 1) and Duration (section 2), the 'Start Test' button; Settings → Speed Unit → WPM; in a trial copy the duration is locked to 2 minutes.
- [ ] **Lesson 2.9**: after saving in Notepad, the file name shows at the top of Notepad.
- [ ] **Is the lab copy registered?** In a trial copy, only the first two lessons of the Touch Typing Course open after 7 days.
