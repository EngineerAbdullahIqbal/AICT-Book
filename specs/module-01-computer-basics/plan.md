## Summary

Turn the scaffolded Docusaurus site into the AICT Course Guide and write Module 1.
Three phases, each test-first:

1. **Test harness**: add Playwright so every later step starts with a failing test.
2. **Site foundation** (the remaining setup tasks d–g): docs-only book with no blog or tutorial,
   strict broken-link checks, Mermaid with a real test diagram on the home page, a sidebar with
   the 16 modules, Urdu text styling, and `aict-guide/CLAUDE.md`.
3. **Module 1 content**: the module overview and 9 lessons, one lesson per task. Each lesson
   starts by adding it to the test list (red) and ends with tests green plus owner review.

Technical approach and sources: [research.md](./research.md). Content rules:
[data-model.md](./data-model.md). Test checks: [contracts/page-contracts.md](./contracts/page-contracts.md).

## Implementation Phases (input for /speckit-tasks)

Every task follows Red → Green → Refactor and ends with a report and the owner's OK.

### Phase 1 — Test harness
1. Install `@playwright/test` and Chromium (R9). Add `playwright.config.js` and the `test`
   script. Red: write `site.spec.js` → `site-title` and confirm it **fails** (title is still
   "My Site"). This proves the harness runs real checks.

### Phase 2 — Site foundation (setup tasks d–g)
2. **Site identity + strict links** (R2): test `site-title` → set title/tagline, remove
   GitHub/editUrl/Docusaurus footer links; add `onBrokenAnchors` and
   `markdown.hooks.onBrokenMarkdownLinks` = `'throw'`.
3. **Remove blog and tutorial, docs-only** (task d, R1): tests `home-at-root`, `no-blog`,
   `no-tutorial` → apply docs-only mode and delete starter files.
4. **Mermaid + home diagram** (task e, R3, R4, R11): tests `home-diagram`,
   `diagram-accessible`, `diagram-in-words` → install theme, configure, add diagram.
5. **16-module sidebar** (task f, R5): tests `sixteen-modules`, `module-placeholders` → add
   16 folders with `_category_.json` + `index.md`.
6. **`aict-guide/CLAUDE.md`** (task g): points to `.specify/memory/constitution.md`,
   `specs/constitution.md`, `specs/book-spec.md`, and the current plan. No test (not a page).
   The owner reviews it.

### Phase 3 — Module 1 content
7. **Module overview + lesson test suite**: write `lessons.spec.js` (contract C3) and
   `module-01.spec.js` (C4); write the `index.md` overview; add the `:lang(ur)` CSS rule (R8).
   The Urdu rule is tested by the first lesson's `key-terms-table` check.
8–16. **One task per lesson, 1.1 → 1.9**: add the lesson to `tests/lessons.js` (red) →
   verify facts (Context7, then Microsoft official pages; R10) → write the lesson → tests
   green → owner review (Urdu, plain language, 60-minute fit, lesson-specific criteria).
   Lesson 1.8 may split if it does not fit 60 minutes (spec §5).
17. **Module check**: full `npm test`, quickstart steps 3–6, list of any UNVERIFIED blocks for
   the owner to test on Windows 11 (laptop) and Windows 10 (lab).
