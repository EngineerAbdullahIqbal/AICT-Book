## Owner decisions

- Use "information", not "data", in this lesson.
- SSD/HDD details move to Lesson 1.3.
- Approved everyday comparison: a student doing a sum (hears numbers = input, thinks =
  processing, writes the answer = output, remembers it = storage). This is a teaching
  comparison, not a technical claim.
- Approved worked example: typing a letter (keyboard → computer works on it → letters on the
  screen → save it).
