## Goal

By the end of this lesson, you can say what an operating system does, and use the desktop, the
Start menu, the taskbar and a window.

## Why It Matters

Every time you turn on a computer, you see the desktop first. You open every program from here.
The computer in a school office and the one in a mobile shop both start this way. When you know
the parts of the desktop, you can find your way on any Windows computer.

In [Lesson 1.2](./hardware-and-software.mdx), you learned that Windows is software. Windows is a
special kind of software called an **operating system**. It is the main software on the computer.
It runs your apps. It controls the hardware, and it looks after your files. It is like the
manager of a shop, who makes sure every worker does the right job.

## Key Terms

| Term | Simple meaning |
|------|----------------|
| Operating system | The main software on a computer. It runs apps and controls the hardware. Windows is an operating system. |
| Desktop | The main work area on the screen. You see it after Windows starts. |
| Icon | A small picture that stands for something you can open, such as an app or a folder. |
| Taskbar | The long bar at the edge of the screen, usually at the bottom. The Start button is on it. |
| Start menu | The list that opens when you select Start. It shows your apps. |
| Search | A place on the taskbar where you type the name of an app to find it. |
| Window | The box on the screen where an open program shows its work. The bar at its top is the **title bar**. |
| Window buttons | Three small buttons on a window: **Minimize** (take out of view), **Maximize** (make bigger) and **Close**. After Maximize, that button becomes **Restore**. |

## Step by Step

Follow these steps on your own computer. Start it up as in
[Lesson 1.4](./starting-up-and-shutting-down.mdx).

**The desktop**

1. Wait until Windows is ready. *You see the desktop.* This is your work area, like the top of
   your table at home. Windows, the operating system, runs every app you open from here.
2. Look at the small pictures on the desktop. Each one is an **icon**. An icon is like the
   sign on a shop: it tells you what you can open.
3. Find the **Recycle Bin** icon. You need it in
   [Lesson 1.8](./files-folders-saving-deleting.mdx) to get back deleted files.

{/* Screenshot to add: The lab computer's desktop, with the icons, the Recycle Bin and the taskbar labelled. */}

**The taskbar**

4. Find the long bar at the bottom of the screen. This is the **taskbar**. You start most of
   your work from here.
5. Find the **Start** button, then **Search** next to it. You use them to open your apps.

<Tabs groupId="windows-version">

The **Start** button is the first item on the taskbar, on the left side. **Search** is to the
right of the Start button.

</TabItem>
<TabItem value="win11" label="Windows 11">

The taskbar icons are in the middle of the taskbar. This is the usual setting. The **Start**
button is the first icon. **Search** is to the right of the Start button.

</TabItem>

6. Find the clock at the right end of the taskbar. *You see the time.*

**Opening and closing a program**

These steps are the same on Windows 10 and Windows 11. You open and close programs many times
every day, so it helps to learn them well.

7. Select **Start**. *You see the Start menu open.* One click is enough here.
8. Type **Notepad**, then select **Notepad** from the results. *You see Notepad open in a
   window.* Do not type anything in Notepad today. Today you practise the window only.
9. Look at the bar at the top of the window. This is the **title bar**. It shows the name of the
   program, so that you know which program you are using.
10. Find the three window buttons at the top-right of the window: **Minimize**, **Maximize**
    and **Close**. **Close** is always the last one. Knowing this stops you closing a program
    by mistake.
11. Select **Maximize**. *You see the window get bigger.* A big window gives you more room to
    work. The Maximize button changes to a **Restore** button. Select **Restore**. *The window
    goes back to its size.*
12. Select **Minimize**. *You see the window go out of view.* The program is still open, like a
    book you put in your bag. Select the Notepad icon on the taskbar to bring it back.
13. Select **Close**. *Notepad closes. You see the desktop again.* Close a program when you have
    finished with it.

## Practice

Your uncle has a computer in his shop. He wants to write his stock list in Notepad, but he
does not know how to open it. Practise these steps on your own, so that you can show him.

1. Look at the desktop. Point to one icon and to the Recycle Bin.
2. Point to the taskbar, the **Start** button, **Search** and the clock.
3. Select **Start**. Type **Notepad**, then select **Notepad** from the results.
4. Point to the title bar. Read the name of the program.
5. Select **Maximize**, so that the window is big. Then select **Restore**.
6. Select **Minimize**. Select the Notepad icon on the taskbar to bring the window back.
7. Select **Close**. Always close a program when you have finished.
8. Do steps 3 to 7 two more times, until you can do them without help.
9. Check your work: Notepad opened in a window, with its name on the title bar. It got bigger,
   then went back to its size. It went out of view and came back from the taskbar. After
   **Close**, you see the desktop again.

## Check Questions

1. What does an operating system do?
   **Answer:** It is the main software on the computer. It runs the apps and controls the
   hardware.
2. Point to the taskbar and the Start button on your computer.
   **Answer:** The taskbar is the long bar, usually at the bottom of the screen. The Start button
   is the first item on it.
3. Which window button closes a program?
   **Answer:** The **Close** button. It is the last of the three window buttons.

## Common Mistakes

- **Double-clicking in the Start menu** → In the Start menu, one click opens an app.
- **Selecting Minimize when you want to close the program** → Minimize only takes the window out
  of view. Select **Close** to close the program.
- **Looking for the Start button on the left in Windows 11** → In Windows 11, the taskbar icons
  are usually in the middle. The Start button is the first one.
