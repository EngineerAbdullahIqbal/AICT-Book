# Module 1: Computer Basics

This is your first module. You do not need to know anything about computers to start.

In this module, you learn what a computer is and what its main parts do. You learn to turn a
computer on and off the right way. You learn to use the mouse and the keyboard. You learn to
find your way around the screen, and to save your work so you can find it again.

## Learning Outcomes

By the end of Module 1, you can:

1. Explain the four jobs of a computer: input, processing, output and storage. Give one everyday
   example of each.
2. Sort a list of things into hardware and software.
3. Point to the main parts of the lab computer and say what each part does.
4. Start the computer and shut it down the correct way.
5. Use the mouse to point, click, double-click, right-click and drag.
6. Find the main groups of keys on the keyboard and use the most common keys.
7. Say what an operating system is, and name and use the main parts of the desktop.
8. Make a folder, save a file in it, find the file again, delete it, and get it back from the
   Recycle Bin.
9. Follow simple rules to keep yourself and the computer safe.
