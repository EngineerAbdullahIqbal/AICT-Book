# Module 2: Typing Skills

In this module, you learn to type with all ten fingers, without looking at the keys. This is
called touch typing. You start with how to sit and where to put your hands. Then you learn the
keys one row at a time. At the end, you type a real paragraph and measure your speed.

**Why it matters:** every later module needs typing. A job letter, an Excel sheet or an online
form is much faster when your fingers know the keys.

**Before you start:** finish Module 1, especially [Lesson 1.6: Keyboard Basics](../module-01-computer-basics/keyboard-basics.mdx).

**Where you practise:** TypingMaster and Notepad. Every lesson has typing drills you can do in
Notepad, so you can always practise.

**Your goal:** a speed of **20 words per minute**, with few mistakes, by the end of this module.

## Learning Outcomes

By the end of Module 2, you can:

1. Sit correctly and place both hands on the home row keys.
2. Type the home row keys with the correct fingers without looking.
3. Type the top row keys with the correct fingers.
4. Type the bottom row keys with the correct fingers.
5. Type capital letters and common punctuation.
6. Type numbers from the number row.
7. Type whole words and sentences correctly, without looking at the keys.
8. Measure your own typing speed and accuracy.
9. Type a short real-life paragraph within a time goal.
