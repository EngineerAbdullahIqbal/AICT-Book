# Module 7: MS Excel

In this module, you learn to keep records and do sums in Microsoft Excel. You type data into
a sheet and make it easy to read. You let Excel add, find averages and find the biggest and
smallest numbers for you. Then you sort your data, make a chart and print your sheet.

The module has three parts:

- **Part 1: Excel Basics** (Lessons 7.1–7.13): cells, typing, formatting, your first formulas,
  sorting, charts and printing.
- **Part 2: More Skills** (Lessons 7.14–7.28): the important formulas used in real jobs: IF,
  COUNTIF, SUMIF, VLOOKUP and XLOOKUP, text and date formulas, and more.
- **Part 3: Real Projects** (Lessons 7.29–7.36): build complete sheets for a shop, an office, a
  school and a home.

**Practice files:** most lessons have a **starter file** to download, with the data already typed
in, and a **finished file** to compare with your work.

**Before you start:** finish Module 1 and Module 4 (Word). Excel uses the same ribbon, and you
save and print in the same way.

**Software:** these lessons use **Excel 2021**, the version on the lab
computers.

## Learning Outcomes

By the end of Module 7, you can:

1. Open Excel and name the workbook, worksheet, row, column, cell and cell address.
2. Type text and numbers into cells, change and clear a cell, and save the workbook.
3. Change column width and row height, and insert and delete rows and columns.
4. Make a table easy to read with font, fill colour, borders and alignment.
5. Show numbers as money, percentages and dates.
6. Write a formula that adds, subtracts, multiplies or divides, using cell addresses.
7. Copy a formula down a column with the fill handle.
8. Use SUM and AVERAGE.
9. Use MIN, MAX and COUNT.
10. Sort a list from A to Z and from smallest to largest.
11. Make a column chart from a small table.
12. Set up a sheet for printing and print it.
13. Build a result sheet with totals, averages, percentages and a chart.
14. Fix a cell in a formula with $, so it stays the same when you copy the formula.
15. Make decisions with IF, IFS, AND and OR.
16. Count and add with conditions: COUNTA, COUNTBLANK, COUNTIF, COUNTIFS, SUMIF, SUMIFS and AVERAGEIF.
17. Find data in a list with VLOOKUP and XLOOKUP.
18. Handle errors with IFERROR, and round numbers with ROUND.
19. Give positions (1st, 2nd, 3rd) with RANK.EQ.
20. Join, clean and split text with text formulas.
21. Work with dates: TODAY, NOW, days between dates and DATEDIF.
22. Use Excel 2021's SORT, FILTER and UNIQUE formulas.
23. Filter data, colour cells with conditional formatting, and freeze headings.
24. Build complete, real sheets for a shop, an office, a school and a home.
