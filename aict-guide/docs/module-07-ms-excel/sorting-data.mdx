## Goal

By the end of this lesson, you can sort a list in A to Z or number order and keep each row together.

## Why It Matters

A shopkeeper wants to find items quickly in a long price list. A school wants to see marks from the highest to the lowest. A family wants its wedding guest list in alphabet order. Sorting puts a list in order in one click. You never need to type the list again.

## Key Terms

| Term | Simple meaning |
|------|----------------|
| Sort | To put a list in order, for example A to Z, or smallest number to largest. It is like arranging books on a shelf. |
| A to Z | Alphabet order for words. Atta comes before Tea. Z to A is the opposite order. |
| Smallest to Largest | Number order: the smallest number first, the biggest last. Largest to Smallest is the opposite. |
| Data tab | A tab on the ribbon. It has the sort buttons. |
| Heading row | The first row of a table. It holds the column names, like Item and Price (Rs). |
| Warning box | A small window where Excel stops and asks you what to do. |
| Expand the selection | A choice in Excel's warning box. It sorts the whole table, so each row stays together. |

Think of each row as one line in a shop register: item, price and quantity. When you sort, the whole line must move together. If only the prices move, every item gets the wrong price.

## Step by Step

You will sort a small grocery price list. Open a new blank workbook (see [Lesson 7.1](starting-excel.mdx)). Type this shop list, starting in cell A1.

| | A | B | C |
|---|---|---|---|
| **1** | Item | Price (Rs) | Quantity |
| **2** | Sugar | 150 | 10 |
| **3** | Tea | 420 | 4 |
| **4** | Atta | 120 | 25 |
| **5** | Rice | 300 | 12 |
| **6** | Oil | 550 | 8 |
| **7** | Daal | 280 | 15 |

**Sort words from A to Z**

This puts the items in alphabet order, so that you can find any item quickly.

1. Look at row 3. Tea costs Rs 420. Remember this, so that you can check it after sorting.
2. Select cell A2. It is one cell in the Item column. One cell is enough. It tells Excel which column to sort by. *Cell A2 is selected.*
3. Select the **Data** tab. *You see the Data tab buttons.*
4. In the **Sort & Filter** group, select **Sort A to Z**. *The items are now in this order: Atta, Daal, Oil, Rice, Sugar, Tea.*
5. Find Tea. It still costs Rs 420. The whole row moved together. *Tea, 420 and 4 are still in one row.*
6. Select **Sort Z to A**. *Tea is now at the top. Atta is at the bottom.*

**Sort numbers from smallest to largest**

This shows the cheapest item first.

7. Select cell B2. It is one cell in the Price column.
8. On the **Data** tab, in the **Sort & Filter** group, select **Sort Smallest to Largest**. *The order is now Atta (120), Sugar (150), Daal (280), Rice (300), Tea (420), Oil (550).*

This is the same button as Sort A to Z. For numbers, it sorts from smallest to largest.

{/* Screenshot to add: The Data tab, with the Sort & Filter group and its sort buttons marked. */}

**The common mistake: sorting one column only**

Now make the mistake on purpose. Then you will know it when it happens, and how to fix it.

9. Drag to select cells B2 to B7 only (the prices). *Only the prices are selected.*
10. Select **Sort Largest to Smallest**. *Excel shows a warning box with two choices: **Expand the selection** and **Continue with the current selection**.*
11. Select **Continue with the current selection**, then select **Sort...**. *Only the prices move. Atta now shows Rs 550. That is wrong!*

:::tip[If your screen looks different]

After you select **Sort...**, a bigger **Sort** box may open. If it does, select **OK** to finish the sort.

:::

12. Select **Undo** (see [Lesson 7.2](entering-editing-saving-data.mdx)), so that the prices go back to their own items. *Every item has its own price again.*
13. Select cells B2 to B7 again. Select **Sort Largest to Smallest**. *The warning box opens again.*
14. Select **Expand the selection**, then select **Sort...** (and **OK** if the bigger box opens). This keeps each row together. *The order is now Oil (550), Tea (420), Rice (300), Daal (280), Sugar (150), Atta (120). Every item keeps its own price.*

Remember: select one cell, not a whole column. If Excel warns you, choose **Expand the selection**.

## Practice

A tuition centre gave a short test. The owner wants the list in name order for the register, and in marks order to see the top students. Open a new blank workbook. Type this list, starting in cell A1.

| | A | B | C |
|---|---|---|---|
| **1** | Name | City | Marks |
| **2** | Zainab | Karachi | 35 |
| **3** | Hina | Multan | 47 |
| **4** | Bilal | Peshawar | 29 |
| **5** | Ayesha | Lahore | 42 |
| **6** | Kamran | Quetta | 38 |
| **7** | Mariam | Faisalabad | 44 |

1. Type the table above. Check every name, city and mark, so that the sorted list is correct.
2. Select one cell in the Name column, for example A3.
3. On the **Data** tab, in the **Sort & Filter** group, select **Sort A to Z**. Ayesha should be first and Zainab last.
4. Select **Sort Z to A**. Zainab should be first and Ayesha last.
5. Select one cell in the Marks column, for example C3. Now Excel will sort by marks.
6. Select **Sort Smallest to Largest**. Bilal (Peshawar, 29) should be first and Hina (Multan, 47) last.
7. Select **Sort Largest to Smallest**. This puts the top student first.
8. Check that every student still has their own city. For example, Ayesha must still be in Lahore.
9. Save the workbook with the name **Test List** (see [Lesson 7.2](entering-editing-saving-data.mdx)), so that your work is not lost.
10. Check your work: the order is Hina 47, Mariam 44, Ayesha 42, Kamran 38, Zainab 35, Bilal 29. The top row is Hina, Multan, 47.

## Common Mistakes

- **Selecting a whole column of cells, then choosing Continue with the current selection** → The rows get mixed up. Select **Undo** at once. Then select one cell only, or choose **Expand the selection**.
- **Sorting by the wrong column** → Look at which column your selected cell is in before you sort. Select **Undo** if the order is wrong.
- **Typing "Rs" in the same cell as the number, like Rs 150** → Excel may not sort it as a number. Type only 150, and write "Rs" in the heading.
- **Not checking the result** → After sorting, check one row. Each name must still have its own city and marks.
