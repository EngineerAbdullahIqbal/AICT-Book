## Goal

By the end of this lesson, you can make a column chart from a small table, give it a title, and move and resize it.

## Why It Matters

A list of numbers is hard to compare at a glance. A chart turns the numbers into a picture. A shopkeeper can see the best day of the week in one look. A family can see where most of the monthly money goes. A mobile shop can see which phone sells the most.

**Diagram in words:** Select the data, then go to Insert, Recommended Charts, All Charts and Column, and select OK. Last, type a title for the chart.

## Key Terms

| Term | Simple meaning |
|------|----------------|
| Chart | A picture made from numbers. It helps you compare them quickly. |
| Column chart | A chart with standing bars. A taller column means a bigger number, like a taller stack of coins. |
| Insert tab | A tab on the ribbon. You use it to add things, like a chart, to the sheet. |
| Recommended Charts | A button on the Insert tab. It opens a window with charts for your data. |
| All Charts | A tab in that window. It shows every type of chart. |
| Chart title | The name at the top of the chart. It tells people what the chart shows. |
| Sizing handles | Small marks on the edge of a selected chart. You drag them to change its size. |

## Step by Step

You will make a chart of one week's sales at a small shop. Open a new blank workbook (see [Lesson 7.1](starting-excel.mdx)). Type these sales, starting in cell A1.

| | A | B |
|---|---|---|
| **1** | Day | Sales (Rs) |
| **2** | Monday | 4500 |
| **3** | Tuesday | 3800 |
| **4** | Wednesday | 5200 |
| **5** | Thursday | 4100 |
| **6** | Friday | 6000 |
| **7** | Saturday | 7300 |

**Make the chart**

First you tell Excel which numbers to draw. Then you choose the kind of chart.

1. Drag from cell A1 to cell B7. Include the headings, so that the chart shows the day names. *Both columns are selected.*
2. Select the **Insert** tab. *You see the Insert tab buttons.*
3. Select **Recommended Charts**. *The **Insert Chart** window opens.*
4. Select the **All Charts** tab. *You see all the chart types.*
5. Select **Column**.

   :::tip[If your screen looks different]

   Excel shows several kinds of column chart. If the chart you get is not a plain column chart, select the chart. Then, under **Chart Tools**, on the **Design** tab, in the **Type** group, select **Change Chart Type** and choose another column chart.

   :::

6. Select **OK**. *A column chart appears on the sheet. Each day has its own column.*
7. Find the tallest and the shortest column. Saturday had the most sales, Rs 7300. Tuesday had the least, Rs 3800. The chart shows this at a glance.

{/* Screenshot to add: The Insert Chart window with the All Charts tab open and Column selected. */}

**Give the chart a title**

A title tells anyone who reads the chart what it is about.

8. In the chart, select the **Chart Title** box. *The title is selected.*
9. Select the title again. Drag over the words in it to select them.
10. Type **Weekly Sales**. *The new title shows at the top of the chart.*

If you see no title box, select the **+** sign at the top-right of the chart. Then select the **Chart Title** check box.

**Move and resize the chart**

You move the chart so that it does not hide your numbers. You make it bigger so that you can read it well.

11. Point to an empty part of the chart. Drag the chart to the right of the table. *The chart moves. The table is no longer covered.*
12. Select the chart. Drag a sizing handle at a corner outwards. *The chart gets bigger.*

    :::tip[If your screen looks different]

    If dragging a sizing handle does not work, select the chart. Under **Chart Tools**, on the **Format** tab, use the **Size** group.

    :::

13. Save the workbook with the name **Sales Chart** (see [Lesson 7.2](entering-editing-saving-data.mdx)), so that your work is not lost.

Excel has other charts too, like a pie chart. This lesson uses column charts.

## Practice

Nadia's family wants to see where the money goes each month. Open a new blank workbook. Type this table of monthly home expenses, starting in cell A1.

| | A | B |
|---|---|---|
| **1** | Item | Amount (Rs) |
| **2** | Groceries | 18000 |
| **3** | Electricity | 6500 |
| **4** | Gas | 2500 |
| **5** | Milk | 4200 |
| **6** | Transport | 5000 |
| **7** | School fees | 7000 |

1. Type the table above. Check every number, so that the chart is correct.
2. Drag from cell A1 to cell B7 to select the table, with the headings.
3. Select the **Insert** tab, then **Recommended Charts**.
4. Select the **All Charts** tab, then **Column**, then **OK**.
5. Look at the chart. Which item has the tallest column? Which has the shortest?
6. Select the **Chart Title** box. Select it again, select the words, and type **Monthly Expenses**.
7. Drag the chart to the right of your table, so that it does not cover any numbers.
8. Make the chart bigger by dragging a sizing handle at a corner, so that you can read it well.
9. Save the workbook with the name **Monthly Expenses**, so that your work is not lost.
10. Check your work: the chart has the title Monthly Expenses and sits next to your table. Groceries (Rs 18000) has the tallest column. Gas (Rs 2500) has the shortest.

## Common Mistakes

- **Selecting only the numbers, without the names** → The chart may not show the item names. Select the names and the numbers, with the headings.
- **Typing "Rs" in the same cell as the number** → Excel may not treat it as a number. Type only the number, and write "Rs" in the heading.
- **The chart covers the table** → Drag the chart to empty cells, to the right of the table.
- **Moving only the title, not the whole chart** → Select **Undo** (see [Lesson 7.2](entering-editing-saving-data.mdx)). Then drag from an empty part of the chart.
