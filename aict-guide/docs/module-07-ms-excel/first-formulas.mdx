## Goal

By the end of this lesson, you can write a formula that adds, subtracts, multiplies or divides
numbers using cell addresses.

## Why It Matters

A shopkeeper adds the day's sales and works out the profit. A family shares a bill between the
people in the house. Excel can do these sums for you. When you change a number, Excel works out
the new answer by itself.

## Key Terms

| Term | Simple meaning |
|------|----------------|
| Formula | A calculation you type in a cell. It always starts with an equal sign (`=`). It is like a sum on a calculator that Excel remembers. |
| Operator | A sign that tells Excel what to do: `+` add, `-` subtract, `*` multiply, `/` divide. |
| Asterisk | The `*` sign. Excel uses it to multiply, not the letter x. |
| Forward slash | The `/` sign. Excel uses it to divide. |
| Result | The answer to a formula. Excel shows it in the cell. |
| Cell address | The name of a cell, like B1: column letter, then row number. See [Lesson 7.1](starting-excel.mdx). |

## Step by Step

Follow these steps on your own computer. Bilal has a small shop. You will work out his sales,
profit and a shared bill. Open a new blank workbook ([Lesson 7.1](starting-excel.mdx)). Type this
table. Type only the words and numbers in columns A and B. Leave cells B3, B5, B8 and B11 empty.
The last two columns are only for checking. Make column A wider
([Lesson 7.3](rows-and-columns.mdx)).

| Row | A | B | Formula for B | Correct result |
|-----|---|---|---------------|----------------|
| 1 | Morning sales (Rs) | 1200 | | |
| 2 | Evening sales (Rs) | 800 | | |
| 3 | Total sales (Rs) | | `=B1+B2` | 2000 |
| 4 | Cost of goods (Rs) | 1450 | | |
| 5 | Profit (Rs) | | `=B3-B4` | 550 |
| 6 | Pens sold | 12 | | |
| 7 | Price of one pen (Rs) | 25 | | |
| 8 | Money from pens (Rs) | | `=B6*B7` | 300 |
| 9 | Bill to share (Rs) | 1500 | | |
| 10 | People | 3 | | |
| 11 | Each person pays (Rs) | | `=B9/B10` | 500 |

**Adding: total sales**

1. Select cell B3. The answer goes here, so you start in this cell.
2. Type `=`. Every formula starts with an equal sign. It tells Excel to calculate.
3. Select cell B1. *B1 appears in the formula.*
4. Type `+`.
5. Select cell B2. *The cell shows `=B1+B2`.*
6. Press **Enter**. *Cell B3 shows 2000.*
7. Select cell B3 and look at the formula bar. This is how you check a formula later.
   *The cell shows 2000. The formula bar shows `=B1+B2`.*

**Subtracting, multiplying and dividing**

8. Select cell B5. Type `=B3-B4` and press **Enter**. Profit is what is left after the cost.
   *B5 shows 550.*
9. Select cell B8. Type `=B6*B7` and press **Enter**. The number of pens times the price gives
   the money. *B8 shows 300.*
10. Select cell B11. Type `=B9/B10` and press **Enter**. The bill divided by the people gives each
    share. *B11 shows 500.*

**Changing a number**

11. The morning sales were really Rs 1500. Select cell B1. Type 1500 and press **Enter**.
    *B3 changes to 2300. B5 changes to 850.*
12. Your formulas use cell addresses, not numbers. So Excel changed the answers for you. You do
    not have to work them out again.

## Practice

Hina's school is going on a trip. Help her plan the money. Type this table, starting in cell A1.
Leave cells B3, B5, B7 and B9 empty. The last column shows the correct result so you can check
your work.

| Row | A | B | Formula to type in B | Correct result |
|-----|---|---|----------------------|----------------|
| 1 | Bus fare (Rs) | 350 | | |
| 2 | Lunch (Rs) | 250 | | |
| 3 | Cost for one student (Rs) | | `=B1+B2` | 600 |
| 4 | Money from home (Rs) | 1000 | | |
| 5 | Money left (Rs) | | `=B4-B3` | 400 |
| 6 | Number of students | 25 | | |
| 7 | Cost for all students (Rs) | | `=B3*B6` | 15000 |
| 8 | Number of groups | 5 | | |
| 9 | Students in each group | | `=B6/B8` | 5 |

1. Open a new blank workbook and type the words and numbers in the table.
2. Select B3. Type `=`, select B1, type `+`, select B2, and press **Enter**. This adds the fare
   and the lunch. Check: 600.
3. In B5, type `=B4-B3` and press **Enter**. This shows what is left from home money. Check: 400.
4. In B7, type `=B3*B6` and press **Enter**. This gives the cost for everyone. Check: 15000.
5. In B9, type `=B6/B8` and press **Enter**. This shares the students into groups. Check: 5.
6. The lunch now costs Rs 300. Change B2 to 300, so that you can see the answers update.
7. Save the workbook with the name **School Trip** ([Lesson 7.2](entering-editing-saving-data.mdx)).
8. Select cell B7 and look at the formula bar.
9. Check your work: B3 shows 650, B5 shows 350, B7 shows 16250 and B9 shows 5. With B7
   selected, the formula bar shows `=B3*B6`.

## Check Questions

1. What must every formula start with?
   **Answer:** An equal sign (`=`).
2. Which signs do you type to multiply and to divide?
   **Answer:** `*` (asterisk) to multiply and `/` (forward slash) to divide.
3. Select a cell with a formula. Point to where you can see the formula.
   **Answer:** The formula bar. The cell itself shows the result.

## Common Mistakes

- **Forgetting the equal sign** → Excel does not calculate. Select the cell, type the formula
  again, and start with `=`.
- **Typing x to multiply** → Use the asterisk (`*`), for example `=B6*B7`.
- **Typing numbers instead of cell addresses**, like `=1200+800` → Use cell addresses, like
  `=B1+B2`. Then the answer changes when a number changes.
- **Typing the wrong cell address** → Select the cell and check the formula in the formula bar.
