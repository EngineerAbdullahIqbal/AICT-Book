## Goal

By the end of this lesson, you can type a small shop list into Excel, correct it and save it as a workbook.

## Why It Matters

A shop has many items, and each item has a quantity and a price. In Excel you write each one in
its own cell. If a price changes, you change one cell, not the whole page. When you save the
workbook, your list is kept for next time.

```mermaid
flowchart TD
    accTitle: Moving after you type
    accDescr: Type in a cell. Press Enter to go to the cell below. Press Tab to go to the cell on the right.
    A[Type in a cell] --> B[Press Enter]

    B --> D[Cell below]
    C --> E[Cell to the right]
```

**Diagram in words:** After you type in a cell, press Enter to go down one cell. Press Tab to go
one cell to the right.

## Key Terms

| Term | Simple meaning |
|------|----------------|
| Data | The words and numbers you type into cells. |
| Tab key | The key marked Tab on the keyboard. In Excel it moves you one cell to the right. |
| Edit | To change what is already in a cell. |
| F2 key | One of the function keys, F1 to F12. In Excel it lets you edit the selected cell. |
| Clear | To remove what is in a cell, so the cell is empty again. |
| Undo | To take back your last action. The keys are **Ctrl+Z**. |
| Save | To keep your workbook as a file, so you can open it again later. |

## Teacher Demo

Open a blank workbook, as in [Lesson 7.1](./starting-excel.mdx). Do each step slowly so the
class can follow. You met the Enter, Backspace and function keys in
[Lesson 1.6](../module-01-computer-basics/keyboard-basics.mdx).

**Typing the headings**

1. Click cell A1. Type **Item** and press **Tab**. *The class sees B1 become the active cell.*
2. Type **Quantity** and press **Tab**.
3. Type **Price Rs** and press **Enter**.

**Typing the items**

4. Click cell A2. Type **Sugar** and press **Enter**. *The class sees A3 become the active cell.*
5. Type the other items in the same way: **Rice**, **Cooking oil**, **Tea**, **Milk**, **Eggs**.
6. Click cell B2. Type the quantities, pressing **Enter** after each one.
7. Click cell C2. Type the prices, pressing **Enter** after each one.
   *The class sees the full list from the table in the Student Task.*

**Editing, clearing and undoing**

8. Say: "The price of milk is now Rs 240." Click cell C6. Press **F2**.
   *The class sees the cursor at the end of 220.*
9. Press **Backspace** two times. Type **40** and press **Enter**. *The class sees 240 in C6.*
10. Click cell A7 (Eggs). Press **Delete**. *The class sees the cell become empty.*
11. Press **Ctrl+Z**. *The class sees Eggs come back.* Say: "Ctrl+Z is Undo."
12. Click any empty cell. Type **abc** but do not press Enter. Press **Esc**.
    *The class sees the typing cancelled and the cell empty.*

**Saving the workbook**

Saving works like saving in Word. See
[Lesson 4.3: Saving, Closing and Opening](../module-04-ms-word/saving-closing-opening.mdx).

13. Press **F12**. *The class sees the Save As dialog box open.*
14. Choose the **Documents** folder.
15. In the **File name** box, type **Shop List**.
16. Select **Save**. *The class sees the Save As dialog box close.*
17. Say: "From now on, press **Ctrl+S** often. It saves your changes."

## Student Task

Type this shop list. Start in cell A1. Type only the number in the price cells. "Rs" is in the
heading only.

| Item | Quantity | Price Rs |
|------|----------|----------|
| Sugar | 2 | 150 |
| Rice | 3 | 320 |
| Cooking oil | 1 | 560 |
| Tea | 2 | 450 |
| Milk | 4 | 220 |
| Eggs | 12 | 30 |

1. Open a blank workbook.
2. Type the three headings in A1, B1 and C1. Use **Tab** to move to the right.
3. Type the items in column A, the quantities in column B and the prices in column C. Use
   **Enter** to move down.
4. The price of milk is now Rs 240. Select cell C6, press **F2** and change 220 to 240.
5. Select cell A5 (Tea) and press **Delete**. Then press **Ctrl+Z** to bring it back.
6. Press **F12**. Save the workbook in **Documents** with the name **Shop List**.
7. Change the quantity of eggs to 24. Press **Ctrl+S** to save again.
8. Show your teacher: your shop list with the new milk price and egg quantity, saved as Shop
   List.

## Check Questions

1. Type a word in any cell. Show which key moves you to the cell on the right.
   **Answer:** The Tab key. (Enter moves you to the cell below.)
2. How do you make a cell empty?
   **Answer:** Select the cell and press Delete.
3. You deleted something by mistake. Which keys bring it back?
   **Answer:** Ctrl+Z (Undo).

## Common Mistakes

- **Typing "Rs 150" in a price cell** → Type only the number, 150. Put "Rs" in the column heading.
- **Pressing Delete when you wanted to change one letter** → Press **Ctrl+Z** to get the data
  back. Then press **F2** to edit instead.
- **Typing over the wrong cell** → Before you type, check which cell has the border around it.
  That is the active cell.
- **Closing Excel without saving** → Press **Ctrl+S** often while you work.
