## Goal

By the end of this lesson, you can insert a table in Word, type in its cells and add a new row.

## Why It Matters

A table puts information in neat rows and columns. A shopkeeper can make a price list with a
table. A school can make a class timetable. Tables make information quick to read and check.

## Key Terms

| Term | Simple meaning |
|------|----------------|
| Table | Information set out in rows and columns, like a grid. |
| Row | A line of boxes that goes across, from left to right. |
| Column | A line of boxes that goes down, from top to bottom. |
| Cell | One box in a table, where a row and a column meet. |
| Tab key | A key on the left side of the keyboard. In a table, it moves you to the next cell. |
| Insert | To add something new to your document, such as a table. |

## Teacher Demo

Open a new blank document ([Lesson 4.1](starting-word.mdx)). You will make a small class
timetable.

| Day | Subject | Time |
|-----|---------|------|
| Monday | Computer | 10:00 |
| Tuesday | English | 11:00 |
| Wednesday | Maths | 10:00 |

**Inserting the table**

1. Say: "Our timetable has 3 columns and 3 rows. Wednesday comes later."
2. Select the **Insert** tab. *The class sees the Insert tab buttons.*
3. Select **Table**. *The class sees a grid of small boxes and a list of choices.*
4. Select **Insert Table**. *The Insert Table box opens.*
5. Type **3** for the number of columns. Type **3** for the number of rows.
6. Select **OK**. *An empty table with 3 columns and 3 rows appears.*
7. Say: "Another way: after **Table**, move the mouse over the grid. Stop when 3 columns and
   3 rows are highlighted."

**Typing and moving between cells**

8. Click in the first cell. Type **Day**. *The word appears in the top-left cell.*
9. Press the **Tab** key. *The cursor moves to the next cell.* Type **Subject**.
10. Press **Tab** again and type **Time**.
11. Press **Tab**. *The cursor moves to the first cell of the next row.* Fill in Monday and Tuesday.
12. Press **Shift+Tab**. *The cursor moves back one cell.* Say: "Shift+Tab goes back."
13. Say: "You can also click in any cell, or use the arrow keys to move."

**Adding a row**

14. Click in the last cell, at the bottom right. It holds **11:00**.
15. Press **Tab**. *A new empty row appears at the bottom.*
16. Type **Wednesday**, **Maths** and **10:00** in the new row.
17. Say: "To add a row in the middle, click in a row first. Then use **Insert Below**."

    :::warning[UNVERIFIED]

    This step could not be confirmed in official documentation for Word 2016/2019.
    Test it on a lab computer before teaching. **Insert Below** is on a table tab that
    appears when you click in a table. One Microsoft page calls this tab **Layout**. Another
    calls it **Table Layout**. Check the name on the lab computer.

    :::

## Student Task

Make a price list for a small shop. Type this table in Word.

| Item | Size | Price |
|------|------|-------|
| Sugar | 1 kg | Rs 160 |
| Rice | 1 kg | Rs 300 |
| Cooking oil | 1 litre | Rs 550 |
| Tea | 250 g | Rs 450 |

1. Open a new blank document.
2. Type **Ali General Store: Price List** on the first line. Press **Enter**.
3. Insert a table with **3** columns and **5** rows (**Insert**, **Table**, **Insert Table**).
4. Type the words from the table above. Use **Tab** to move to the next cell.
5. Click in the last cell (**Rs 450**). Press **Tab** to add a new row.
6. In the new row, type **Milk**, **1 litre** and **Rs 220**.
7. Make the top row bold ([Lesson 4.5](formatting-text.mdx)).
8. Save the document as **Price List** ([Lesson 4.3](saving-closing-opening.mdx)).
9. Show your teacher: your price list with 6 rows, a bold top row and Milk in the last row.

## Check Questions

1. Point to one cell in your table. Then point to one row and one column.
   **Answer:** A cell is one box. A row goes across. A column goes down.
2. Which key moves you to the next cell? Which keys move you back?
   **Answer:** **Tab** moves to the next cell. **Shift+Tab** moves back one cell.
3. Your table needs one more row at the bottom. Show how you add it.
   **Answer:** Click in the last cell, at the bottom right, and press **Tab**.

## Common Mistakes

- **Pressing Enter to go to the next cell** → Press **Tab** to move to the next cell.
- **Choosing the wrong number of rows or columns** → Undo it ([Lesson 4.2](typing-and-correcting-text.mdx)) and insert the table again. If you need one more row, press **Tab** in the last cell.
- **An extra empty row appears at the bottom** → You pressed **Tab** in the last cell. Undo it with **Ctrl+Z**.
- **Typing outside the table** → Click inside the cell you want before you type.
