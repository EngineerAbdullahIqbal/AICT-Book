# Module 4: MS Word

In this module, you learn to make real documents in Microsoft Word. You type text, fix
mistakes and save your work. You make your text clear and neat. You add lists, tables and
pictures. Then you print your work.

At the end, you make two documents for real life: a job application letter and your own CV.

**Before you start:** finish Module 1. You need the mouse and the keyboard.

**Software:** these lessons use **Word 2016** and **Word 2019**, the versions on the lab
computers.

## Learning Outcomes

By the end of Module 4, you can:

1. Open Word, start a blank document and name the main parts of the Word window.
2. Type text, correct mistakes and undo a change.
3. Save a document with a name in a folder you choose, close it, and open it again.
4. Select text, and copy, cut and paste it.
5. Change the font, size, colour and style of text.
6. Change how a paragraph lines up, and the space between lines.
7. Make bulleted and numbered lists.
8. Find and fix spelling and grammar mistakes.
9. Insert a table and type in it.
10. Insert a picture and a shape.
11. Set up the page, preview your document and print it.
12. Write and format a job application letter.
13. Make a simple one-page CV.
