# Module 5: MS PowerPoint

In this module, you learn to make slides in Microsoft PowerPoint. You add slides, type and
format text, choose a design, and add pictures, a table and a chart. Then you add movement
between slides and show your slides on the full screen.

At the end, you make a short presentation for a mobile shop's new products.

**Why it matters:** shops, schools and offices use slides to explain an idea, a product or a
result. A neat presentation helps you at work, in college and in freelancing.

**Before you start:** finish Module 4 (Word). PowerPoint uses the same ribbon, and you format
and save text in the same way.

**Software:** these lessons use **PowerPoint 2021**, the version on the lab computers.

## Learning Outcomes

By the end of Module 5, you can:

1. Open PowerPoint, start a blank presentation and name the main parts of the window.
2. Add new slides, choose a slide layout, and type a title and points.
3. Save a presentation, open it again, and show it full screen as a slide show.
4. Format text on slides: font, size, colour and bullets.
5. Give the whole presentation a matching look with a design theme.
6. Add a picture and a shape to a slide.
7. Add a table and a simple chart to a slide.
8. Put slides in order: move, copy and delete slides.
9. Add a transition between slides.
10. Add a simple animation to text or a picture.
11. Write speaker notes, and print handouts or notes pages.
12. Plan and make a 6-slide presentation for a real purpose.
